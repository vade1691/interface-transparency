# Interface Transparency

A RuneLite plugin that lets you adjust the transparency of the side panel menu tabs, the chat tabs and the minimap orbs and surround.

## Features

Each area has its own settings section, with a choice between one slider for everything or separate sliders for each element.

- **Resizable modern:** tab stones, tab icons, the panel background and the panel border.
- **Resizable classic:** tab stones, tab icons, the side pillars and the panel background.
- **Chat tabs:** the chat tab buttons and their background.
- **Minimap:** the orbs (health, prayer, run energy, special attack, store, world map, wiki, recommendations and XP drops) and the minimap surround.

Turn on **Use one slider for all** in a section to control everything in it with a single slider, or turn it off to set each element separately.

Sliders run from 0% (fully transparent) to 100% (the game's normal appearance).

## Tips

- For the best result in the resizable classic layout, turn on **Transparent side panel** in the game's Interfaces settings.
- For the chat tabs, turn on **Transparent chatbox** in the same settings.
- The plugin works alongside the game's own transparency settings. At 100% it changes nothing.

## Notes

- This plugin only changes the opacity of existing interface widgets. It does not hide or add any information, and it does not affect gameplay.
- Text widgets, such as the chat filter text and the numbers on the orbs, are ignored by the game's opacity setting, so they do not fade with the elements around them.
- The minimap surround is only partly supported in the resizable classic layout so far.
