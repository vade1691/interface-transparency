# Menu Tab Transparency

A RuneLite plugin that lets you adjust the transparency of the side panel menu tabs:
the tab stones, their icons and the panel background.

## Features

- One slider for the **resizable modern** layout and one for the **resizable classic** layout.
- Each slider fades the stones, icons and panel background together.
- Works alongside the game's own transparency settings: at 100% the plugin changes nothing.
- The slider stops at 10% so the tabs can't be made invisible by accident.

## Tip

For the best result in the resizable classic layout, turn on **Transparent side panel**
in the game's Interfaces settings.

## Notes

This plugin only changes the opacity of existing interface widgets. It does not hide
or add any information.
